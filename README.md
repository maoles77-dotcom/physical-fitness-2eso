# Physical Fitness · La condición física (2º ESO)

Interactive bilingual website (English / Spanish) for the 2º ESO Physical Education unit **"Physical Fitness"**.
Web interactiva bilingüe (inglés / español) del tema **«Physical Fitness»** de Educación Física de 2º ESO.

**▶ Live site / Web:** https://maoles77-dotcom.github.io/physical-fitness-2eso/

## Features / Qué incluye

- **Three reading modes / Tres modos de lectura:** English, Spanish, or both side by side (EN · EN+ES · ES).
- **Tap-to-translate words / Palabras traducibles:** tap any underlined word to see its translation and hear its pronunciation.
- **Animated illustrations / Ilustraciones animadas:** endurance (aerobic/anaerobic), strength (concentric, isometric, eccentric), flexibility, balance, coordination and agility.
- **Reaction-time game / Juego de tiempo de reacción** for speed.
- **Summary map / Mapa resumen** of all the physical abilities.
- **Vocabulary / Vocabulario:** 85 words with search, categories, pronunciation and flashcards.
- **Quiz / Cuestionario:** 12 questions with bilingual feedback.
- Dark mode, pause-animations button, works on phone, tablet and computer. / Modo oscuro, botón para pausar animaciones y diseño adaptado a móvil, tablet y ordenador.

## Use / Uso

It is a static website: open `index.html` in a browser or visit the link above. No installation needed.
Es una web estática: abre `index.html` en el navegador o entra en el enlace. No hace falta instalar nada.
